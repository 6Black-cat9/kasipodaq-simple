# Проверка версии 1.0.0

Проверено 6 октября 2026 года. Все проверки выполнены с реальным PHP API, SQLite и файловым хранилищем; ответы не подменялись.

## Среда

- PHP 8.2.34 + Apache 2.4, mod_rewrite, PDO_SQLite, Fileinfo; минимальная заявленная версия PHP 8.2.
- Дополнительно PHP 8.3 CLI со встроенным HTTP-сервером.
- Chromium + Playwright, 1440×1000 и 390×844.
- Для тестов использованы отдельные папки данных. Тестовые SQLite-базы, сессии, пользовательские загрузки и config.php отсутствуют в архиве.

## Результаты

- Все 8 PHP-файлов: синтаксис валиден на PHP 8.2 и 8.3.
- JavaScript: проверка синтаксиса и ESLint no-undef/no-unused-vars/eqeqeq — без ошибок.
- **34 интеграционных API-теста прошли**: вход, CSRF, bcrypt, права, личные данные, создание/редактирование/удаление члена, заявки, статус/история/комментарии, новости и черновики, документы/PDF/загрузки, события/участие, уведомления, защита администратора, настройки, SQL-инъекция, поиск по казахскому тексту, статистика/периоды, блокировка повторной установки, выход, профиль, пароль, отзыв сессии при смене роли, закрытые вложения, лимит файлов, некорректный тип изображения.
- `browser.mjs`: публичные страницы; вход члена; заявка с реальным PDF; комментарий; запрет ADMIN для MEMBER; вход администратора; все страницы панели; изменение статуса; удаление с подтверждением; новость с фото, изменение и удаление; мобильное меню, главная и таблица без горизонтального переполнения страницы. Ошибок JavaScript нет.
- `browser-management.mjs`: создание/редактирование/удаление члена с фото; вход нового члена и сохранение профиля; изменение роли; загрузка/изменение/удаление документа; CRUD мероприятия; сохранение настроек; фильтр статистики и пять диаграмм; чтение уведомлений. Ошибок JavaScript нет.
- 8 одновременных первых обращений: атомарное создание схемы без ошибок.
- Apache в режиме загрузки всего проекта в корень: `/` перенаправляет в `/public/`; интерфейс и API работают из подпапки. REST rewrite `/public/api/news` работает. Запросы к app/schema.sql, storage/базе, seed-documents, config.example.php, tests и public/router.php запрещены с HTTP 403.
- Чистый ZIP распакован и запущен отдельно: первая установка без демо, создание администратора, вход, пустая статистика и HTML работают. Проверка CRC всех 49 файлов успешна.
- OpenAPI 3.1: 51 операция, статическая документация без внешних JS-библиотек.

## Границы проверки

Проверка выполнена локально в серверном окружении. Доступа к вашему хостингу и GitHub-репозиторию не предоставлено: архив не опубликован на внешнем домене. При загрузке на ваш тариф проверьте наличие PHP 8.2+, PDO_SQLite, Fileinfo, поддержку `.htaccess` и запись PHP в storage. Архив запускает новую SQLite-базу; данные старого PostgreSQL-проекта не переносились.

Файлы и пароли для тестов — демонстрационные. Для реальных данных создайте своего администратора, отключите или измените демо аккаунты и используйте HTTPS.
